## 1. Executive Summary

**HSE Career Agent** is a private, production-grade desktop career intelligence platform. Upgraded in Phase 2 from a rules-based application into a comprehensive AI-powered career assistant, it parses your Master CV, maintains an editable verified career profile, compares vacancies with your background using Google Gemini, and delivers explainable career matching recommendations at zero monthly cost.

### Key Capabilities in Phase 2:
- **Master CV Upload & Parsing**: Supports PDF and DOCX files. Automatically extracts text using PyMuPDF (`fitz`) and `python-docx` to extract employment history, qualifications, competencies, and achievements.
- **"My Career Profile" Section**: A dedicated interactive dashboard view to inspect, correct, and confirm all fields of your professional background. Original CV files are stored locally and securely in `data/cv/`.
- **Configurable Google Gemini Integration**: Uses the official `google-genai` SDK with the free-tier model `gemini-2.5-flash`. Hardcoded keys are prohibited; your API key is loaded exclusively from backend environment variables.
- **AI Job Matching & Fit Breakdown**: Generates structured 100-point suitability scores, matching competencies, gap analysis, qualification alignment, industry alignment, reasons to apply, and reasons to reconsider.
- **Career Growth Scoring (Separately Evaluated)**: An independent 0-100 career opportunity score evaluating leadership expansion, multi-country regional scope, and international mobility.
- **International Eligibility & Visa Analysis**: Rigorously evaluates explicit visa sponsorship statements and local work authorization requirements across India, Singapore, Germany, Netherlands, Ireland, and Australia without making unsupported assumptions.
- **Strict Privacy & Security Controls**: Raw CV files are kept strictly on your local computer (`data/cv/`). An explicit consent toggle must be activated before sending structured profile criteria to Gemini. Local network services bind only to `127.0.0.1`.
- **Zero-Cost Hard Quota & SHA-256 Caching**: Computes SHA-256 hashes of vacancies to provide instant cached evaluations without consuming API calls. A daily request limit (50 requests/day) prevents unexpected usage.
- **Transparent Local Fallback Engine**: If the Gemini API key is missing or quota is exhausted, the local rules-based engine runs seamlessly. The UI transparently indicates whether an evaluation was generated by "Gemini AI" or "Local Rules Fallback".

## 3. Quick Start & Setup Instructions

### Step 1: Launch Application
- Double-click **`START_HSE_AGENT.bat`** (or execute `.\scripts\start_app.ps1` in PowerShell).
- Open your browser to **`http://localhost:3000`**.

### Step 2: Configure Free Gemini API Key (Optional but Recommended)
1. Go to Google AI Studio at **[https://aistudio.google.com/](https://aistudio.google.com/)** and create a free Gemini API key.
2. In the `HSE-Career-Agent` root folder, create or edit your `.env` file:
   ```env
   GEMINI_API_KEY="your_actual_gemini_api_key_here"
   GEMINI_MODEL="gemini-2.5-flash"
   GEMINI_DAILY_LIMIT=50
   ```
3. Restart the application via `STOP_HSE_AGENT.bat` and `START_HSE_AGENT.bat`.
*(If no API key is provided, the application will automatically and safely run the local rules-based engine at ₹0 cost.)*

### Step 3: Upload Master CV & Confirm Profile
1. In the sidebar, click **"My Career Profile"**.
2. Your verified background (Raghunath Reddy, Global SHE & Security Manager at dsm-firmenich, 18+ years, APAC 19 plant reporting) is pre-populated as a verified baseline.
3. Click **"Upload Master CV (PDF or DOCX)"** to upload your latest resume.
4. Text is extracted locally using PyMuPDF or python-docx without leaving your computer.
5. Review and edit any field (roles, degrees, skills, achievements), then click **"Save & Confirm Profile"**.
6. Switch on the **"AI Suitability Analysis"** consent toggle to authorize Gemini matching.

### Step 4: Run AI Job Matching
1. In the sidebar, click **"Discover Jobs"**.
2. Click any job to open the **Job Details Modal**.
3. In the "AI Career Match & Fit Analysis" section, click **"AI Analyze Job"**.
4. Within 2-3 seconds, review the 100-point AI match score, Priority badge, Career Growth score progress bar, Reasons to Apply, Reasons to Reconsider, and direct evidence quotes.

## 5. Privacy, Security & Quota Controls

- **Local File Security**: Uploaded Master CV documents are stored locally in `data/cv/` and are never uploaded to cloud storage or public buckets.
- **Explicit Consent**: Profile criteria are sent to Gemini only when the user explicitly enables the consent toggle in "My Career Profile".
- **Zero Paid Cost Guarantee**: Defaults strictly to free-tier usage (`gemini-2.5-flash`). Paid fallback is hard-disabled.
- **Daily Quota Limiter**: Enforces a default daily limit of 50 requests tracked in `AIUsageLog`. When the quota is reached, the application automatically switches to local rules matching without interrupting the user.
- **SHA-256 Caching**: Identical job postings produce the same hash and return cached results instantly, consuming 0 API quota.
- **No Public Network Exposure**: FastAPI and Next.js are bound strictly to `127.0.0.1` / `localhost`.

## 6. Known Limitations

- **Public ATS Feeds Only**: Crawls official public feeds from Greenhouse and Lever. Unsanctioned scraping of login-walled sites (like LinkedIn) is omitted to prevent IP blocking and preserve stability.
- **Sponsorship Verification**: While explicit statements in vacancy text are extracted accurately, employers that do not mention sponsorship policies are categorized as `Unknown` rather than assumed.
- **Free Tier Quotas**: Google Gemini Free Tier is subject to standard rate limits (15 RPM / 1,500 RPD). The application's caching and daily cap safeguard against quota depletion.
